协议覆盖

三种调用形式，一个引擎

每个协议都按官方事件序返回流式帧，工具调用以协议原生形态出现——这正是 agent 循环真正解析的东西。tool_choice 语义三协议互通，token 计数、前缀缓存与 TTFT/TPOT 完全同口径。

OpenAI Chat Completions

POST /v1/chat/completions

  • 流式：data: chunk 逐帧 + [DONE]，含 include_usage
  • 工具调用：delta.tool_calls 参数按 24 字符分片，拼接即合法 JSON
  • 收尾：finish_reason = tool_calls / length / stop

OpenAI Responses

POST /v1/responses · GET /v1/responses/{id}

  • 流式：response.created → output_item.added → *_delta → response.completed
  • 工具调用：function_call 条目 + function_call_arguments.delta，call_id 回填
  • 多轮：previous_response_id 服务端链式上下文

Anthropic Messages

POST /v1/messages

  • 流式：message_start → ping → content_block_* → message_delta → message_stop
  • 工具调用：tool_use 块（toolu_* id）+ input_json_delta；tool_result 回填续轮
  • 收尾：stop_reason = tool_use / max_tokens / stop_sequence
能力

为 agentic 负载而设计

mock 的价值在于「形状正确」：token 数精确、延迟可建模、缓存可命中、指标可抓取、压测可复现。

精确 token 计数

仓库自带 deepseek_v3_tokenizer 时按真实 tokenizer 精确计数，输出严格等于 max_tokens；缺失时回退确定性启发式。同 seed 完全可复现。

三协议 fake 工具调用

按 tools 的 JSON Schema 合成参数（路径/命令/内容有真实感），流式参数分片拼回即合法 JSON；tool_result / function_call_output 回填后循环正常终止。

64-token 块前缀缓存

blake2b 块哈希 + trie 前缀匹配 + LRU 序列淘汰，共享 system 前缀可跨会话命中；命中率同时体现在计数器与 TTFT 上。

TTFT / TPOT 延迟模型

首 token = prefill（未命中 token 数）+ 排队 + 抖动；每 token = 配置 TPOT。--max-concurrency 制造排队，复现「容量拐点」。

vLLM 风格指标

Prometheus 命名子集（prefix_cache_*、time_to_first_token 等）+ /api/stats 的 p50/p90/p99 分位数，Prometheus 与面板直接可用。

闭环压测 bench

python -m bench sweep：chat/coding/agentic/longctx 四种 profile，一条命令出 MD/CSV/PNG/SVG 与容量曲线。

FAQ

常见问题

同样的问题也以结构化数据（schema.org FAQPage）提供给搜索引擎与 AI 回答引擎。

GPT-Zero 是什么？

一个纯离线的多协议 Mock LLM 推理服务（PyPI 包 openai-mock，Python 包 gptzero）。它不是模型、不产生有意义的回答，而是复现推理服务在 agentic 负载下的可观测行为：精确 token 计数、TTFT/TPOT 延迟、排队、缓存命中、流式工具调用帧与成功率。

支持哪些 API 协议？

三套协议共用同一引擎：OpenAI Chat Completions（/v1/chat/completions）、OpenAI Responses（/v1/responses，含 previous_response_id 链式多轮与 GET 检索）、Anthropic Messages（/v1/messages），JSON 与 SSE 双模式，另保留旧版 /v1/completions。

fake 工具调用是怎么实现的？

按请求里的 tools JSON Schema 合成参数合法的工具调用，并按协议原生流式形态输出：Chat 用 delta.tool_calls 分片、Responses 用 function_call + function_call_arguments.delta、Messages 用 tool_use（toolu_* id）+ input_json_delta。工具结果回填后返回普通文本，agent 循环正常终止。

token 计数准确吗？

准确。仓库自带 deepseek_v3_tokenizer 时按真实 tokenizer 精确计数，输出严格等于 max_tokens；否则回退确定性启发式。两种模式下同 seed 可复现。

怎么安装？

pip install openai-mock 后运行 gptzero --port 8090；或 docker run --rm -p 8090:8090 ghcr.io/potterluo/gpt-zero:latest（amd64/arm64 双架构）。把 OpenAI SDK 的 base_url 指向 http://127.0.0.1:8090/v1，或 Anthropic 客户端的 base_url 指向 http://127.0.0.1:8090 即可。

开源协议与收费？

Apache-2.0 开源，完全免费。协议适配形态参考 deepseek-recipe（MIT）的协议转换思路，只取协议转换部分，不做 tokenizer 转换。
